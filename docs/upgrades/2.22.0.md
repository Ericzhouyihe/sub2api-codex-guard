## CI Failure and Fix

The first image build failed during `go mod download` after upstream added
`github.com/google/jsonschema-go v0.4.2`. The module is available on the configured
proxy, so the failure was a transient/proxy-checksum issue. `docker-image.yml` now
passes `GOPROXY=https://proxy.golang.org|https://goproxy.cn|direct` and
`GOSUMDB=sum.golang.org`; the Dockerfile retries `go mod download` once. The
retriggered build succeeded.
