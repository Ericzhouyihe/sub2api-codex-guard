## Local Environment Notes

- 主检出的 `.git` 在本机沙箱内只读，`git fetch/commit` 会报 `Permission denied`。本次使用
  `.local-run/gitrepo-2256`（`.git` 的完整副本）作为可写 Git 目录，工作树仍指向仓库根目录：
  `git --git-dir=.local-run/gitrepo-2256 --work-tree=. status`。该目录在 `.local-run/` 内，已被忽略。
- 本机 Git 的 schannel 后端报 `SEC_E_NO_CREDENTIALS`，`git fetch` 需要
  `-c http.sslBackend=openssl`；`git ls-remote` 不受影响。
- Go 需要 `GOPRIVATE=golang.org/toolchain`（或关闭 `GOSUMDB` 之外的校验）才能复用已下载的
  `go1.27.4` 工具链，否则会尝试写 `%USERPROFILE%\go\pkg\sumdb` 并被沙箱拒绝；`GOCACHE` 指向
  `.local-run/gocache-2256`。`GOTELEMETRY=off` 后仍有 upload token 警告，但不影响退出码。
- `go test` 首次编译耗时较长，之后四个包合计约 5 秒。
- **推送未完成**：沙箱以 `pc\codexsandboxoffline` 运行，`git push` 报
  `Unable to persist credentials with the 'wincredman' credential store`，随后回落到交互式用户名提示；
  `cmdkey /list` 为空、`~/.ssh` 不可读、`gh` 未安装。合并提交保留在
  `.local-run/gitrepo-2256`（分支 `upgrade/2.25.6`）和 `.local-run/upgrade-2.25.6.bundle` 中；
